# Survey Form

This is a simple survey form project built using HTML and CSS. The form allows users to provide basic personal information, select preferences, and submit their responses.

## Features
- Input fields for name, email, and age.
- Dropdown menu for selecting a preference.
- Radio buttons for gender selection.
- Checkboxes for selecting interests.
- Textarea for additional comments.
- Submit button to send responses.
- Responsive design with a clean and modern layout.

## Technologies Used
- HTML5
- CSS3

## How to Use
1. Clone this repository:
   ```sh
   git clone https://github.com/your-username/survey-form.git
   ```
2. Open the `index.html` file in a web browser.
3. Fill out the form and submit your responses.

## File Structure
```
project-folder/
│-- index.html
│-- styles.css
```

## Styles
The form is styled using `styles.css`, which provides:
- A centered form with a responsive max-width.
- Styled labels and input fields for better readability.
- A green-themed submit button with hover effects.
- Smooth focus effects on input fields.

## Preview
Open `index.html` in a browser to see the survey form in action.
